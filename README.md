# In Every Generation

הדשבורד והתסריט של הסרט. כל דחיפה ל-`main` עולה לאתר תוך דקה-שתיים.

| קובץ | מה זה |
|---|---|
| `dashboard.html` | הדשבורד: התוכן נמצא בבלוק `PROJECT` בראש הקובץ |
| `script.html` | התסריט: אנגלית, עברית, פרקים ועברית מעודכן (`UPDATED`) |
| `materials/` | התסריט המקורי של הלקוח |
| `index.html` | דף התסריט המקורי, בלי השינויים. נשאר בכתובת הישנה |

הריפו ציבורי, והתסריט של הלקוח עוד לא יצא: לא להפיץ את הקישורים.
סימוני "מוכן" ו"בוצע" וההערות ברואים שומעים נשמרים בדפדפן של כל אחד ולא עוברים בין אנשים.
